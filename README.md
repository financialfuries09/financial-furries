# Financial Furries

A zero-cost static starter website for **Financial Furries — "Gain financial knowledge. Be furious."**

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `financial-furries`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/root`, then save.
6. GitHub will provide a free `github.io` website address.

## Before publishing real financial news
- Replace the demo market figures with verified data from a licensed/authorized source.
- Add original articles rather than copying other publications.
- Attribute and link to primary sources.
- Add publication dates and corrections when needed.
- Review the disclaimer and privacy requirements for your jurisdiction.
- Connect the newsletter form to an email provider only after checking its free-tier limits and privacy terms.

The current market figures and article content in this demo are placeholders and should not be presented as live financial data.
